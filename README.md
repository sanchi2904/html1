# 🌐 Basic Web Development Project

## 📌 Project Overview
This project contains a collection of simple and interactive web pages created using **HTML, CSS, and JavaScript**. The project demonstrates basic web development concepts such as forms, calculators, navigation menus, alerts, button interactions, and webpage design.

It is designed for learning and practicing front-end web development fundamentals.

---

## 📂 Project Files

### 1. `basic_form.html`
A simple HTML form that collects user input using different form elements such as:
- Text fields
- Buttons
- Labels
- Input validation

### 2. `calculator.html`
A basic calculator webpage that performs arithmetic operations such as:
- Addition
- Subtraction
- Multiplication
- Division

### 3. `color_button.html`
An interactive webpage where button colors change or perform color-related actions using JavaScript.

### 4. `greeting_alert.html`
A webpage that displays greeting messages or alert pop-ups based on user interaction.

### 5. `navigation_menu.html`
A simple navigation menu demonstrating webpage navigation links and menu structure.

### 6. `simple_webpage.html`
A basic webpage structure showcasing:
- Headings
- Paragraphs
- Styling
- Basic webpage layout

### 7. `image.png`
Image asset used in the project for webpage design or display purposes.

## 🛠️ Technologies Used
- **HTML5** – Structure of webpages

## 🚀 How to Run the Project

### Method 1: Open Directly
1. Download or clone the repository.
2. Open the project folder.
3. Double-click any `.html` file to open it in a web browser.

### Method 2: Using VS Code
1. Open the project folder in **VS Code**.
2. Install the **Live Server** extension.
3. Right-click any HTML file.
4. Click **"Open with Live Server"**.
